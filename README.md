## Project Overview

This project analyzes Netflix titles data using Python and visualizes key metrics in a user-friendly dashboard. The goal is to explore insights related to genre distribution, country availability, and content types.

###  Features
- Data analysis using **Pandas**
- Data storage in **MongoDB**
- Backend built with **Express.js** and **Node.js**
- Basic frontend to display results
- Screenshots and report included
