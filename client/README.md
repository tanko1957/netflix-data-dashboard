# Netflix Data Analytics Dashboard

This project combines data analytics with full-stack web development to explore and visualize trends in Netflix content using a dataset from Kaggle.

## Project Overview

- Python was used to analyze the Netflix dataset and compute:
  - Total entries
  - Content types (Movies vs TV Shows)
  - Top 5 producing countries
  - Content release trends by year
- Results were inserted into a MongoDB database.
- A Node.js + Express backend serves the data as an API.
- A simple HTML/JS frontend fetches and displays the stats.

##  Technologies Used

- Python (Pandas, Pymongo)
- Node.js + Express
- MongoDB Atlas
- HTML/CSS/JavaScript
